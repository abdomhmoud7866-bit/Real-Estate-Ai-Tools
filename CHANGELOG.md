# Changelog

## 0.3.0

- Added a local client CRM and property inventory with follow-up dates, lead stages, availability, and handover tracking.
- Added reusable developer plans for irregular dated installments, contract milestones, and post-handover payments.
- Added investment proposals with property details, rent and financing assumptions, branded PDF print layouts, and optional WhatsApp sharing from a reviewable summary.
- Added commission splits and a sales performance dashboard with monthly targets and conversion metrics.
- Added IndexedDB persistence with validated JSON backup and restore, individual record deletion, and workspace-wide erase.
- Added broker workspace translations for English and Arabic and improved mobile navigation.
- Refreshed the offline asset cache and expanded unit and browser coverage.
- Prepared separate flat deployment, complete source, and test suite ZIP packages.

## 0.2.0

- Introduced THE SPIDER DXB, a responsive workspace for UAE real estate analysis.
- Preserved rental yield and side-by-side developer payment plans, and added monthly installment schedules.
- Added mortgage, property comparison, resale, and cash flow calculators.
- Added English and Arabic layouts, theme controls, and an offline application cache.
- Added print layouts for saving branded PDF reports from the browser.
- Added automated financial and browser tests and a continuous integration workflow.
- Added a contribution guide, security policy, and development roadmap.

## 0.1

- Added the original rental yield calculator and developer payment plan comparison.
- Published a static, dependency-free page with illustrative AED inputs and an MIT license.
